# SimpleWorship Brand Identity

## Official Mark
**Product Name:** SimpleWorship
**Short Name:** SW

## Brand Assets
The official supplied brand assets are authoritative and must be preserved without modification.

### Core Assets Directory
`public/branding/logo/`
- `SimpleWorship-SW-primary.png` (Default horizontal lockup or SW mark)
- `SimpleWorship-SW-white.png` (Light/White horizontal lockup for dark backgrounds)
- `SimpleWorship-SW-dark.png` (Dark horizontal lockup for light backgrounds)
- `SimpleWorship-icon.png` (Standalone 'SW' app icon)
- `SimpleWorship-full.png` (Full logo)
- `SimpleWorship.ico` (Windows executable icon)

## Usage Rules
- **No Logo Redesign:** The supplied logo must never be redrawn using text, CSS, or SVG shapes.
- **Application vs Presentation:** The application's identity (SimpleWorship) remains fixed. User-provided church/ministry logos are for presentation overlay only and do not replace the application identity.
- **UI Scaling:** Assets should be referenced centrally via `src/config/branding.ts` to ensure single-source-of-truth accuracy across the UI.
- **Color Palette (Reference from Asset):**
  - Primary: `#1296F3`
  - Secondary: `#00BCD4`
  - Accent: `#9C27B0`
  - Background: `#0D1321`
  - Foreground: `#F0F2F5`
